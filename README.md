# B2B Finder Pro

أريد بناء تطبيق ويب تفاعلي متخصص في التنقيب عن الشركات التجارية (B2B Intelligence). التطبيق يجب أن يكون بواجهة عربية احترافية تدعم اتجاه اليمين إلى اليسار (RTL). المكونات المطلوبة:

حقل بحث لإدخال اسم السلعة (مثل: يوريا، حديد، قمح).

حقل لتحديد الدولة أو المنطقة الجغرافية.

جدول لعرض النتائج المستخرجة يتضمن: (اسم الشركة، النشاط التجاري، الموقع الإلكتروني، زر للواتساب، زر لإرسال عرض سعر بالإيميل).

تصميم نظيف واحترافي مناسب لبيئة عمل تجارية. أريد برمجة وظيفة (Search Handler) تقوم عند إدخال اسم السلعة والدولة، بالبحث في المواقع الرسمية وغرف التجارة (عن طريق أدوات بحث متقدمة) لاستخراج بيانات الشركات وعرضها في الجدول الذي أنشأناه. اجعل النتائج قابلة للتنقية (Filtering) حسب النشاط."
